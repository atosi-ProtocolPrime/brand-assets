4. App Branding & Sub-Brand Strategy

A branded house approach maintains a unified corporate identity across the entire portfolio:

Phase 1: Master Brand Lockup (Current Standard)

  • Structure: All products utilize the identical "Prime Node" parent logo icon to maximize brand recognition and equity.
  • Typography Lockup: The primary logo icon is paired directly with the sub-brand name (e.g., "PrimeTrack", "PrimeCapture", "PrimeConnect") set in Geist.
  • Strategy: Establishes a cohesive enterprise ecosystem, reassuring users that all tools share the same security, performance, and UI standards.

Phase 2: Color-Coded Domain Ecosystem (Future Roadmap)

  • Structure: The geometric structure of the Prime Node icon remains strictly uniform across all products.
  • Domain Accents: The central node's accent color shifts based on product domain (e.g., Electric Amethyst for PrimeTrack, Cyber Teal for PrimeCapture, Warm Accent for PrimeConnect).
  • Strategy: Gives sub-brands distinct visual identities while keeping them clearly tied to the master ProtocolPrime platform.

5. Product Ecosystem Portfolio

PrimeTrack
Domain: Language & Localization (l10n).
Core Focus: Complex localization project management, timeline tracking, resource orchestration, and translation memory/workflow pipelines.
Architectural Rule: Enforce strict i18n/l10n data isolation. Abstract string repositories from presentation logic. All dates, timestamps, currencies, and metric units must support dynamic locale formatting.
PrimeCapture
Domain: IT & Precision Capture Utility.
Core Focus: Lightweight, low-latency, high-precision screen capture, image annotation, and automated API publishing/upload execution.
Architectural Rule: Maximize speed and minimize memory footprint. Decouple OS-level screen capture hooks, clipboard interaction, and network upload threads. Execute asynchronous background tasks without blocking UI loops.
PrimeConnect
Domain: AI & Human Connection Platform.
Core Focus: Universal cross-platform AI icebreaker and connection facilitator for social, platonic, and professional onboarding contexts.
Architectural Rule: Enforce strict real-time privacy and payload encryption. Isolate AI prompt engineering, context evaluation engines, and dynamic topic generators from the client display layer.
